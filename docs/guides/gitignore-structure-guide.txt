1. OS & IDE (Системні налаштування):
    - .DS_Store, Thumbs.db — системні файли кешу іконок та папок (macOS/Windows).
    - *.swp, *.bak — тимчасові файли відновлення та резервні копії редакторів.
    - .vscode/, .idea/ — локальні налаштування середовищ розробки (VS Code, PyCharm).
    - .python-version — файл вказівки версії Python для pyenv.

2. Backend (Python & Django):
    - venv/, .venv/, ENV/ — віртуальні середовища Python.
    - __pycache__/, *.py[cod] — скомпільований байт-код Python.
    - db.sqlite3 — локальний файл бази даних SQLite.
    - media/ — папка для завантажених користувачами медіа-файлів.
    - static/, stickfiles/ — папки для зібраної статичної інформації Django.
    - celerybeat-schedule, celerybeat.pid — службові файли планувальника завдань Celery.
    - .pytest_cache/, .coverage — тимчасові файли та звіти тестування.

3. Frontend:
    - node_modules/ — залежності фронтенд-частини проєкту.
    - frontend/dist/, frontend/dist-ssr/ — результат збірки фронтенду (production build).
    - npm-debug.log*, yarn-debug.log*, pnpm-debug.log* — лог-файли помилок різних менеджерів пакетів Node.js.
    - .eslintcache — кеш інструмента для перевірки якості коду ESLint.
    - .cache/ — папки кешування різних інструментів збірки (наприклад, Vite або Babel).

4. Security & Logs (Загальне)
    - .env, .env.* — файли з конфіденційними змінними оточення (паролі, ключі).
    - *.local — будь-які локальні файли конфігурації.
    - logs/, *.log — файли логів роботи застосунку та пакетних менеджерів.
